# CodeJudge Database System - Part 2

## Objective

This repository contains SQL query implementations for the CodeJudge dataset.

The work includes:

* retrieval queries
* filtering
* joins
* aggregation
* HAVING clauses
* subqueries
* validation notes
* SQL reasoning explanations

---

## Files Included

| File             | Purpose                                        |
| ---------------- | ---------------------------------------------- |
| queries.sql      | All SQL queries                                |
| query_outputs.md | Query purpose, output summaries and validation |
| sql_reasoning.md | SQL reasoning explanations                     |

---

## Database

The queries are written using SQLite compatible SQL syntax.

---

## Notes

The queries are based on the normalized schema created in Part 1.
